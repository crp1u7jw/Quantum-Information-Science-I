I made this because I wanted to get used to making physics simulations. Coding simulations is a considerably different experience from other forms of coding like game design and data processing. It is centered on creating clean, modular code withstands the stress test of complex physics.

While coding this, I learned many things like how to write clean code, how to decide the level of modularity (based on the scope of the project), and how to moderate my workflow as I take on larger-scale projects like this. 

Having this experience will help me considerably in simulating quantum mechanics later in this course as I will already have experience creating physics based simulations.
